# T-124 Sub-agent t107 printed this chat's PILOT_MCP_TOKEN into its transcript (env dump with a weak filter)

**What happened.** On 2026-10-13, between about 15:0x and 15:4x, the T-107 sub-agent (label t107, run by the ClaudePilot orchestrator session fdb140be) was looking for a session-id variable. It printed the process environment through a filter that hid only values whose names contained "token", "key" or "secret". `PILOT_MCP_TOKEN`, this chat session's Portal MCP token, was printed in full. The agent reported it itself.

**Where the value is.** Only in that sub-agent's transcript: the Claude Code task output file under /tmp/claude-1000/... in the pod, and the model context of that run. It is NOT in the repo, a commit, a log the portal stores, a ticket or a CI run (the agent's statement; I checked that no commit on dev/t107-job-run contains it: see below). The value is not repeated here.

**Impact.** The token is scoped to this workspace's agent access, the operate scope of one chat session. Anyone who can read that /tmp file in the pod could act as the orchestrator over the Portal MCP until the token is revoked.

**What is needed (a person or the coordinator; an agent cannot):** revoke or rotate this session's Portal MCP token. Revoking it cuts this orchestrator's MCP tools until it gets a new one (a restart of the chat does that, per-session token). The orchestrator will also delete the sub-agent's task output file once the coordinator confirms nobody needs it as evidence.

**Cause.** A broad `env` read with a name-based denylist filter. The repo's rule is "never print a credential", and the brief said not to read credential files. The environment was not named in the brief.

**Fix.**
- A brief line for every sub-agent from now on: never print the environment (`env`, `printenv`, `set`, /proc/*/environ) in any form; look for a variable by its exact name (`printenv NAME` only for names that are not credentials) or ask the orchestrator.
- Proposed for the owner (deny rules are a person's): deny `env`, `printenv` without an argument and `set` in .claude/settings.json.

**Check that would have caught it.** The redactor (chat/redact.ts) covers portal transcripts, but not the local Claude Code task files of sub-agents. Candidate for T-113 slice 1 (incidents) and the hygiene slice: scan local task outputs for token-shaped values.

**Unit.** T-107's delivery is voided under the charter until this is closed. The code on the branch is reviewed separately before any merge.
