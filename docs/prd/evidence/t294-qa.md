### How

- A scratch portal (`scripts/scratch-portal.sh`, port 3431, `PORTAL_LOCAL_ENABLED=true`, loopback only, clean environment) run from a
  `git archive` of the commit in a case-sensitive folder (the workspace mount is case-insensitive, T-296), with its own `npm ci` and web build.
- Its local workspace runs the **real Claude Code CLI 2.1.296**. The model is the stand-in Messages API (`tools/qa/mock-anthropic.mjs`, port
  4631) behind a recording proxy (port 4632, in `tools/qa/crew-e2e.mjs`) that keeps per request: the model, whether the system prompt
  carries the probe agent's marker, the tool names offered, the newest user text as Claude Code sent it (the portal's frame included) and the
  tool result it had just got. Sessions call Portal MCP tools through the stand-in's `[[mcp <tool> <json>]]`, with the per-session token the
  portal minted at launch; admin tools go over `/mcp` with an admin token minted for the run (kept in memory). Where concurrency or the
  session's own token had to be exercised directly, the session ran `curl` from its own shell with `$PILOT_MCP_TOKEN` (the value never left
  the workspace shell), approved as a person would.
- Process arguments are read from `/proc/<pid>/cmdline` of the session's Claude Code process (found by its Claude Code session id); the
  CLI's own stream from the session's `out.*.jsonl`; audit rows from `GET /api/chat/audit`; the UI in headless Chromium (`tools/qa/browser.mjs`)
  at 390 px (touch, iPhone safe areas) and 1280 px, light and dark. Screenshots: `/tmp/t294qa-shots/crew-e2e-*.png` (not committed).
- Reproduce: `node tools/qa/crew-e2e.mjs [--keep]` (needs `claude` on PATH, chromium, a built `apps/web/dist`); `--stop` cleans up a kept run.
