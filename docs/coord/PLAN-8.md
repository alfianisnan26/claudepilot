## 2. Principles
O1. EXTEND, DO NOT REBUILD; NO COLLISIONS: surgical hooks only after the owning agent has reported done (the coordinator says when); adapters over existing seams otherwise; list every hook in your report.
O2. SECURITY FIRST AND ABUSE TESTED: findings never hold a full secret (mask at the source: store only a fingerprint, a short masked excerpt and the location; never log values); exceptions are by fingerprint and reason, not by regex that can hide a class; an auto-approval rule can never reach Bypass or a high-risk action, and matching is strict (parse the command into tokens, reject shell operators, substitutions, redirections, newlines, environment prefixes and anything not exactly covered; the rule names the tool and the exact command or path pattern; wildcards only inside a single argument position and never across an operator); evasion is tested ("npm test; curl ...", "npm test && ...", "npm test $(...)", "npm  test", quoting tricks, path traversal in path rules, symlinks, a rule for one workspace used in another); every automatic approval is audited with the rule id and the exact input; rules expire and count uses; a suggestion needs a confirmation; cleanup never removes data it cannot prove is an orphan of THIS portal, always lists first, and requires a confirmation for anything not recreatable.
O3. NUMBERS AND CLAIMS NEVER INVENTED; unavailable is shown as unavailable; guardrails are described as guardrails, not guarantees.
O4. EVERY AUTOMATIC ACTION has a limit checked before acting, an audit entry, and a visible trail (and a notification once the PLAN-5 event bus exists).
O5. ONE USER: no roles; per-device state is per device.
