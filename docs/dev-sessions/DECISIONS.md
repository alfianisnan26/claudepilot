A decision is changed only by the owner (or by a later row that says it supersedes this one); an agent that disagrees says so with evidence on a ticket, and does not act against a standing row. Until the portal's decisions registry exists (T-115, which imports this file as its first entries), this file is the registry. Ids are stable; never renumber.
