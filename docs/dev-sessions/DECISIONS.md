# Standing decisions

The owner's decisions and the defaults taken under them, in one place, so an agent follows them instead of re-deriving or contradicting them. Read before you plan. A decision is changed only by the owner (or by a later row that says it supersedes this one); an agent that disagrees says so with evidence on a ticket, and does not act against a standing row. Until the portal's decisions registry exists (T-115, which imports this file as its first entries), this file is the registry. Ids are stable; never renumber.
